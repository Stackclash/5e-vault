For post-session wrap-ups: draft the journal (summary + body sections) in the reply with a short numbered question list, get answers, then write the file and the canon deltas in one pass.

**Why:** validated on the S44 wrap — the DM answered six numbered questions in one terse pass and approved the canon deltas as a batch. Writing a journal with guessed dates/details first would have put wrong canon in the vault; asking one question at a time would have burned his time.

**How to apply:** every session-log task. Keep the question list tight and numbered so it can be answered inline. Bundle the canon deltas (NPC `condition`, `partyRelationships`, `player_impression`, campaign-bible Active Threads) into the same approval, and file them into the canonical notes rather than only into the journal.

Related: **do not create NPC notes for nameless, one-off characters** — the DM declined a note for the S44 dwarf who gave a false confession, even though the character had a real plot function and is still in custody. Record that kind of detail in the journal and in the relevant NPC's `secrets` instead. See [[campaign-state]].
