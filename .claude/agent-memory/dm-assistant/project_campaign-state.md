Rebuilt to **CR 17** (Large, 315 hp, legendary actions/resistances) purely as a deterrent block, not a scheduled encounter. His new monstrous growths carry the same amber veining as Warden conduits and Marrow's graft — a by-sight reveal about Vecna's *reach*, not his plan.
