# Datacore Scripts

React (TSX) components for the [Datacore](https://github.com/blacksmithgu/datacore) plugin. Located in `z_Scripts/Datacore/`.

## Overview

Datacore is the successor to Dataview, using React for rendering. The vault currently has one Datacore component.

## `FilterTable.tsx`

**File:** `z_Scripts/Datacore/FilterTable.tsx`

A reusable React component that renders a filterable, searchable data table. Features:

- Column-based filtering
- Text search across all fields
- Sortable columns
- Configurable data sources

This component is used where interactive table filtering is needed beyond what Dataview tables provide.
