# DM Prep Templates

Templates for session planning and post-session journaling. Located in `z_Templates/Templater/DM Prep/`.

## Session Journal

**File:** `z_Templates/Templater/DM Prep/Session Journal.md`

Creates a post-session journal entry for recording what happened during a game session. The template collects:

- **Party** — selects from available parties
- **Session date** — date the session took place
- **Session number** — auto-incremented or manually set

The generated note includes structured sections for session summary, key events, and follow-up items. Journal entries are stored in the configured session journals folder.

## Session Prep

**File:** `z_Templates/Templater/DM Prep/Session Prep.md`

Creates a pre-session preparation note for planning an upcoming game session. The template collects:

- **Party** — selects from available parties
- **Session date** — planned date

The generated note provides structured prompts and sections for encounter planning, NPC preparation, plot hooks, and session goals. Prep notes are stored in the configured session preps folder.
